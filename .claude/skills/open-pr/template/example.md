### Implementation

대시보드 요청은 전달 계층을 거쳐 메인 admin 패키지가 응답하고 있었고, 계산 규칙과 검증 범위는 메인 코드에만 있었습니다.

<br>

1. 메인의 계산 규칙(빈 날과 빈 달을 0으로 채우기, 이번 달만 집계 중 표시)과 검증 범위(일 1~365, 월 1~36)를 그대로 옮겼습니다.
2. 조회는 메인 DB 읽기 전용 연결로 바꾸고, 응답은 메인과 같은 필드와 타입으로 맞췄습니다.
3. 헤더 조건을 단 채 배포해 prod 메인과 응답을 비교했고, 차이가 없어 헤더 조건을 지웠습니다.

<br>

> [!NOTE]
> Plan과 달라진 점: 범위를 벗어난 요청의 오류 메시지 형식이 두 서버에서 달라, 관리자 API 전용 예외 처리기를 두어 메인 형식에 맞췄습니다.
